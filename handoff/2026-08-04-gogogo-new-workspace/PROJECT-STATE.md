# GOGO GO 项目进度

## 项目目标

使用单页 HTML 作为长期 AI 从业者学习入口，课程、课卡、训练、错题、复习和浏览器进度都留在页面；Codex 负责解释、追问、作业审核和长期反馈，不依赖 Claude。

## 已发布基线

提交：`af0c6e3 Expand advanced certificate learning flow`

已发布能力：

- 14 个学习关卡。
- 基础课程与高级证书扩展。
- 高级阶段 64 张课卡、128 道题的数据契约。
- 初学者导读、术语词卡、每课理解表达。
- 训练与系统审核、错题回课卡、进度持久化。
- GitHub Pages 线上入口可用。

## 最新用户验收要求

- 中央任务卡只能位于用户截图红框所示尺寸范围。
- 中央人物必须显示在任务卡上层，不能被任务卡遮挡。
- 中央任务卡不再显示 STEP 01–05 完整列表。
- 只显示当前关卡、当前 STEP、下一关预告和下一步具体行动。
- 当下一步是重点笔记时，按钮直接显示“复习重点笔记”。
