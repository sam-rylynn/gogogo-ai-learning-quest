# GOGO GO 产品记忆与决策

## 长期方向

- 用户以后完全在 Codex 中学习，不依赖 Claude。
- HTML 是行动、训练和进度层；Codex 是解释、纠错、语义审核和反馈层。
- 日常最小闭环是：课程页 → 学习与训练 → 复制单课审核包 → Codex → 带回反馈。
- 页面不能假装自动读取 Codex 对话，也不能因为没有复盘材料而制造任务。
- 学习者按零基础设计，课程必须先讲清概念、词义、流程、案例、反例和边界。
- 题目深度不能超过书库实际教学深度。

## 当前学习结构

- 课程书库：完整知识输入。
- 我的复盘：个人表达、疑问、错误证据与 Codex 回执。
- 本关训练：判断题、选择题和即时诊断。
- 错题档案：聚合弱点并返回对应课卡。
- 72h 复测塔：间隔复训。
- 项目作品陈列门：将学习结果转为作品与能力证据。

## “我的复盘”第一性原理

复盘的价值不是复制教材摘要，而是保存可被纠正的个人理解。

- 无表达就没有复盘项，不能把未写的课卡自动列为待办。
- 20 字只决定表达是否可以送审，不等于理解正确。
- 训练与复盘互补，复盘不再作为训练前强制门槛。
- 复制审核包只记录 copiedAt，不自动确认。
- 回执必须由用户显式粘贴和保存。
- 回答、疑问或课程内容任一变化，旧回执都不能继续计为当前确认。
- notes 只表示真实疑问，wrong 只提供错题行动入口，lastResult 只展示最近训练证据。
- 旧 keyNoteReviewed 仅兼容旧存储，不代表新模型中的确认。

## Codex 回执契约

单课卡审核包要求 Codex 返回三行：

    状态：通过 / 需要修改 / 信息不足
    关键问题：指出最重要的一处理解问题
    追问或提示：给出下一步思考方向

网页保存回执证据，但不负责替代 Codex 的语义判断。

## 内容标准

每张课卡至少包含：

- 零基础定义。
- 中文与英文术语。
- 它解决什么问题。
- 输入、处理、输出。
- 正例、反例和边界。
- 常见错误。
- 与前后知识的连接。
- 一段学习者自己的理解表达。

## 视觉与交互标准

- 保持 2D 像素公会氛围。
- 任务板不超出场景边界，不遮挡前景人物，不增加蒙版。
- 六个入口的框架、字体、颜色和交互语言统一。
- 学习弹窗标题随内容滚动，不使用影响阅读的强制吸顶。
- 桌面、平板和窄屏都不能出现页面级横向溢出。
- 键盘焦点、关闭后归还、浏览器缩放和当前位置语义属于发布质量要求。

## 证书与推广边界

- GOGO GO 是独立学习训练工具，不是官方课程、官方备考或报名平台。
- 必须分别说明证书颁发方和类型。
- WorkBuddy OPC 属于腾讯云厂商认证语境。
- AI 智能体应用开发工程师材料属于中国电子学会培训证书语境。
- “连续 3 次达到 85 分”是产品自己的高级阶段训练门槛，不能写成官方报名或考试规则。
- 不承诺全国统一的补贴、落户、职称或证书排名。
