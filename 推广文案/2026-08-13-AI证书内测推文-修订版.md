# 想转AI，怎么系统地学？我研究3个月后，做了一个闯关式学习网站

> 我不是AI专家，也不是培训机构。
>
> 我在传统行业做了十年，现在想转向AI产品运营。这篇文章记录了我怎么选证书、怎么准备，也想邀请一批和我处境相似的人，来试试我做的学习网站。

---

## 一、想转AI，我也纠结过要不要考证

中国人对考证并不陌生。

当一个行业太新、岗位要求又说不清时，一张证书至少能给人两样东西：一份相对明确的学习范围，和一个必须完成的期限。

我承认，我也需要这些。

我在商业地产做了十年招商，擅长的是跟人沟通、问需求、找问题。决定转AI产品运营以后，我最先问的不是“该学哪个模型”，而是：

> 这么多证书和课程，我到底该信哪一个？

我查了三个月。证书名目繁多，发证主体各不相同，价格也能从几百元一路到几千甚至更高。

刚开始，我也想做一张“含金量排行榜”。越查越发现，这样排很容易误导人。不同证书解决的问题不一样：

- 职业技能等级证书，要看评价机构是否经过当地人社部门备案；补贴条件也因地区、等级和当期政策而异。
- 培训评价或专业技术培训证书，主要证明参加过相应培训并通过考核，不等于职业资格证、职称证或上岗证。
- 厂商认证通常更贴近具体平台和工具，适不适合你，要看目标岗位是否真的使用这套生态。

所以我后来不再问“哪张证全国最值钱”，而是先问五个更实际的问题：

1. 证书到底由谁颁发？能不能在颁发机构官网查到？
2. 它属于职业技能等级、培训评价，还是厂商认证？
3. 有没有公开、明确的课程大纲和考核方式？
4. 课程内容和我想去的岗位有没有关系？
5. 学完以后，我能不能留下一个作品或一份可验证的能力证据？

按这个方法，我先保留了三个与自己转型方向最接近的能力方向：AI产品方向、智能体应用方向、AIGC办公应用方向。在智能体应用方向上，我个人考察过腾讯WorkBuddy效率智能体OPC从业者认证：腾讯云培训认证官网将其列为专项认证的Practitioner（从业者）级别，通过考试后由腾讯云颁发官方电子证书；其课程、考试、费用和有效期，以官网当期信息为准。

这不是一份适合所有人的推荐名单，也不代表每个方向都要考证。我的目标很具体：用产品方法打底，补上AI办公和智能体应用能力，再单独判断自己是否需要报考；如果决定报考，就按对应证书的官方大纲重新准备。

## 二、方向选出来了，我却发现自己还没准备好

选证书并没有让我立刻踏实下来。

我试过视频课、电子书和记笔记。看的时候都懂，关掉页面过几天，再让我用自己的话讲一遍，脑子里只剩几个名词。

更麻烦的是坚持。课程往往很长，反馈又来得慢。今天少学一点，明天再拖一下，一个月以后，我还在第一章。

那段时间我慢慢意识到：我不是不想考证，也不是觉得证书没用。我只是缺一条能从零开始系统学习、同时留下实操证据的路线。

于是我没有急着报名，而是先给自己做了一个学习工具。

---

## 三、我把这些岗位要用的能力，做成了14关

这个网站叫《GOGO GO · AI从业者闯关之路》。它不是任何发证机构的官方课程，也不代替官方教材和考试通知。

我做它的目的很简单：把“我要补什么能力”继续拆成“我今天到底学什么、练什么、留下什么”。

整条路线一共14关，可以按自己的节奏推进：

```text
第1—6关 · AI基础
提示设计 → Python / API → 机器学习
→ Transformer → RAG / 工具调用 → 小型AI产品

第7—14关 · 应用能力路线
WorkBuddy → Coze智能体 → CLI Agent / 私有化部署
→ AI产品方法 → 运营自动化 → AI视觉与影音
→ 作品集与训练复盘
```

我不想再把“看完”当成“学会”，所以每张课卡后面都有一段闭卷表述。先合上教材，用自己的话写下来。页面只记录文字，不判断内容是否正确；如果想继续追问，可以手动复制学习快照到Codex或其他AI助手，也可以完全不用外部服务。

网站里还有随机训练、答题解析和错题档案。高级阶段目前配置了128道客观题，全部为我个人在站内编写，不是任何机构的真题或模拟题。我给自己设的内部训练门槛是：连续3轮达到85分。

这个85分只说明我对本站题库的训练比较稳定；它不是任何发证机构的报名条件。外部证书的考试范围、题型和本站题库并不相同，是否报考、如何准备，都要以发证方当期官方大纲和规则为准。

网站目前免费，不需要注册。学习记录只保存在当前浏览器的当前网址，不同域名和设备不会自动同步。它不会自动读取你的Codex对话；需要反馈时，由你自己把学习快照复制过去，回不回复、用哪个AI服务都由你决定。

## 四、它更适合这些人

| 你现在的状态 | 可以怎么用 |
| --- | --- |
| 想系统学AI，但分不清应该先学什么 | 先看完整能力路线，再决定是否考证，不急着付费 |
| 零基础，看到Python、RAG就头大 | 从第1关开始，一次只完成一张课卡 |
| 想转AI产品或运营 | 先补前6关基础，再进入AI产品与运营路线 |
| 已经买了课，但看完总是记不住 | 用理解表述、随机训练和错题复训检查自己 |
| 已经会用很多AI工具，却没有作品 | 沿着后半段补项目、测试记录和作品集证据 |

如果你只想找代报名、押题或“快速拿证”，这个网站目前帮不上忙。它更适合愿意先学一遍、做一遍，再判断证书是否值得考的人。

## 五、现在，它开放公开试用

这个网站还在早期公开试用阶段，很多地方肯定不够顺手，课程内容也会继续校对。

如果你愿意自己试试，不需要一次学完一关。第一次只做四件事：

1. 打开第1关，读完第一张课卡；
2. 不抄原文，写一段自己的理解；
3. 完成一轮训练，看看答错后的解释是否看得懂；
4. 自己记录三个观察：哪里看不懂、哪里操作卡住，以及第二天你还愿不愿意继续打开。

这次公开试用不收集统一反馈。你可以先按上面四步自测，看看第二天还愿不愿意打开。

试用地址：https://gogogo-ai-quest.pages.dev/course

学习记录只保存在当前浏览器的当前网址，不同域名和设备之间不会自动同步；页面内的“导出”只含旧版基础进度，不含我的复盘、统一训练成绩和公会证据。换网址、换设备或清理浏览器数据前，请另行复制关键内容。

对你来说，值得试一试的不是“这个网站看起来像不像一个游戏”，而是它能不能帮你——一个想转AI、又总怕自己坚持不下来的人——每天往前走一步。

如果你正好是这样的人，欢迎来试试。
